# Kaggle Hello World

Kaggleを「機械学習を試す場所」としてではなく、**データ → 分析 → モデル → 共有**までを一周させる場所として理解するための3分入門です。

## 3分でやること

1. Kaggle Notebookを開く
2. Pythonを実行する
3. 小さなデータを作る
4. pandasで眺める
5. scikit-learnでモデルを作る
6. 予測する
7. Notebookとして残す
