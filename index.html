Kaggle Hello World

3分で、
機械学習を一周する。

Kaggleを始めるとき、いきなり難しいコンペを見る必要はありません。 まずは「データを読む → モデルを作る → 予測する」。 この小さなループを一度、自分の手で回してみます。

Data→Explore→ Feature→Model→ Predict→Share

1. Kaggleは何なのか

KaggleにはDataset、Notebook、Model、Competitionなどがあります。 NotebookではPythonやRを使って、データ分析や機械学習を実行できます。 DatasetをNotebookに追加して分析し、結果を共有する、という使い方ができます。

つまりKaggleは「モデルだけを作る場所」ではありません。 データを持ってきて、実験して、結果を残し、他の人と共有するための環境です。

2. Hello World

まずは本当にHello World。

print("Hello, Kaggle!")

これだけでも、Kaggle Notebookでコードを実行するという最初の一歩になります。 Notebookはセル単位でコードと文章を書き、実行結果を残せます。

3. 次に「データ」を作る

機械学習は、まずデータが必要です。 ここでは外部Datasetを探さず、自分で小さなデータを作ります。 

import pandas as pd

df = pd.DataFrame({
    "size": [20, 30, 40, 50, 60],
    "price": [200, 300, 390, 520, 610]
})

df

sizeとpriceという2つの数字があります。 ここから「sizeからpriceを予測できるか？」という問いを作れます。

4. モデルを作る

from sklearn.linear_model import LinearRegression

X = df[["size"]]
y = df["price"]

model = LinearRegression()
model.fit(X, y)

ここで初めて「モデル」が登場します。 モデルは、与えられたデータから関係を学習します。

5. 予測する

prediction = model.predict([[70]])

print(prediction)

70という新しいsizeを渡すと、priceの予測値が返ってきます。 これで機械学習の最小ループが完成しました。

データ → 学習 → 予測

たったこれだけです。難しいアルゴリズムを覚える前に、 この流れを体験することが重要です。

6. Kaggleらしさは、その先にある

ここからDatasetを大きくしたり、可視化したり、特徴量を増やしたり、 モデルを比較したりできます。 さらにNotebookを共有し、他の人のNotebookを読んだりforkしたりできます。

次は、こんな流れになります。

公開データ
  ↓
Dataset
  ↓
Notebook
  ↓
EDA
  ↓
Feature Engineering
  ↓
Model
  ↓
Prediction
  ↓
共有・比較

KaggleではDatasetをNotebookの入力として追加でき、 Notebookの出力を別のDatasetとして利用することもできます。 そのため、単発の実験だけでなくデータ処理の流れを組み立てることもできます。

7. そして、Kaggleは「モデル作成」だけではない

ここが最初に勘違いしやすいところです。 Kaggleでは確かにモデルを作れます。 しかし、モデルはイベントフローの一つのノードです。

Observe→Data→ Experiment→Model→ Prediction→Decision→Action

モデルを作って終わりではありません。 予測を使って何をするのか。 その結果、新しいデータが生まれ、次の実験につながります。

まとめ

Kaggle Hello Worldで覚えることは、難しい機械学習ではありません。 

データを見る
    ↓
問いを作る
    ↓
モデルを作る
    ↓
予測する
    ↓
結果を残す
    ↓
次のデータへ

まず一周する。
それから大きなデータ、大きなモデル、大きな問題へ進めばいい。
